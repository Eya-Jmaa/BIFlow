# BIFlow demo script

1. Start `docker compose up --build`.
2. Open http://localhost:3000.
3. Create project **E-Commerce BI Analysis** with a real objective.
4. Upload Olist CSVs from `data/raw/olist/` (see `data/documentation/olist.md`).
5. Run the pipeline and keep the Pipeline screen open.
6. After completion, walk Quality → Semantic → KPIs → Insights → Dashboard → Audit.
7. Click a KPI and show formula, SQL, lineage and XAI.
8. Export PDF/Excel from Settings.
9. Repeat with UCI Online Retail to show the platform is dataset-agnostic.
